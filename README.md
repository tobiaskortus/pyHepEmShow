# pyHepEmShow
A pybind 11 wrapper for HepEmShow for detector optimization

## Dependencies

https://github.com/SciCompKL/g4hepem

https://github.com/SciCompKL/hepemshow

## Installation 

```sh
cd pyHepEmShow
pip install -e .
```

```sh
pip install git+git@github.com:tobiaskortus/pyHepEmShow.git
```
